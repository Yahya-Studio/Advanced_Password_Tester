# فاحص قوة كلمات المرور 🎯
أداة متقدمة لتحليل كلمات المرور وتقييم قوتها باستخدام خوارزميات التشفير الحديثة.
## نظرة عامة
هذا المشروع هو تطبيق ويب متكامل لتحليل كلمات المرور، يوفر تحليلاً شاملاً ومفصلاً لكلمة المرور المدخلة من حيث القوة والأمان. يتميز التطبيق بواجهة مستخدم عربية كاملة وداعمة للوضع الداكن.
## التقنيات المستخدمة
- **React 19** - إطار عمل واجهة المستخدم
- **TypeScript** - لغة البرمجة المحددة الأنواع
- **Vite** - أداة بناء المشاريع السريعة
- **Tailwind CSS** - إطار العمل للتصميم
- **Lucide React** - مكتبة الأيقونات
## المميزات
### 1. تحليل قوة كلمة المرور
- حساب درجة القوة من 0 إلى 100
- تحديد المستوى (ضعيفة / مقبولة / جيدة / قوية / ممتازة)
- شريط بصري متعدد الألوان يعكس القوة
### 2. تحليل الـ Entropy
- حساب إنتروبيا كلمة المرور (bits)
- حساب عدد التركيبات الممكنة
- تحليل نوع البركة (pool) المستخدمة
### 3. وقت الكسر المتوقع (Brute Force)
- تقدير وقت الكسر بحاسوب عادي (10 billion 시도/ثانية)
- تقدير الوقت بحاسوب خارق (100 trillion ثانية)
- تقدير الوقت على مستوى دولة (1 quadrillion/ثانية)
### 4. تحليل تركيب الأحرف
- عدد الأحرف الصغيرة (a-z)
- عدد الأحرف الكبيرة (A-Z)
- عدد الأرقام (0-9)
- عدد الرموز الخاصة (!@#$%^&*)
- رسم بياني دائني لتوزيع الأحرف
### 5. تحليل الأنماط
- اكتشاف التتابعات الشائعة (123, abc, qwerty)
- اكتشاف كلمات المرور الشائعة
- اكتشاف تكرار الأحرف
- اكتشاف أنماط لوحة المفاتيح
- اكتشاف السنوات (تواريخ الميلاد)
### 6. اقتراح كلمات مرور قوية
- توليد كلمات مرور عشوائية قوية (16 حرف)
- تحتوي على جميع أنواع الأحرف
- يمكن استخدامها مباشرة
### 7. النصائح والتوصيات
- تحذيرات ونصائح مخصصة لكل كلمة مرور
- اقتراحات للتحسين بناءً على التحليل
- ترتيب النصائح حسب الأولوية

## خوارزمية التحليل
### حساب الدرجة
الدرجة النهائية تحسب بناءً على:
- طول كلمة المرور (أقصى 40 نقطة)
- تنويع أنواع الأحرف (أقصى 20 نقطة)
- الـ Entropy (أقصى 30 نقطة)
- نسبة الأحرف الفريدة (أقصى 20 نقطة)
- وجود رموز خاصة (+10 نقاط)
- طول 12+ حرف (+10 نقاط)
- طول 16+ حرف (+10 نقاط)
### الخصومات
- أحرف فقط: -10 نقاط
- أرقام فقط: -30 نقطة
- أحرف متكررة: -30 نقطة
### تحليل الـ Entropy
```
Entropy = length * log2(poolSize)
poolSize = 26 (a-z) + 26 (A-Z) + 10 (0-9) + 32 (symbols)
```
### وقت الكسر
```
seconds = 2^entropy / guessesPerSecond / 2
```
